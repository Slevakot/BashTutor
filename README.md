# Контрольная работа №2
Тема: «CSS-фреймворки: разработка веб-интерфейсов»

## Название проекта
BashTutor — Образовательная платформа по командам Bash

## Описание
Образовательный веб-ресурс, предназначенный для изучения команд командной строки Bash. Проект содержит базовую навигацию, каталог категорий, популярные команды, схему обучения (Roadmap) и форму обратной связи. Сайт сверстан с использованием CSS-фреймворка Bootstrap.

## Структура проекта
```
bash-guide/
├── index.html
├── css/
│   └── custom.css
└── README.md
```
## Реализованный функционал (Главная страница)

- Подключен Bootstrap 5 через CDN;
- Добавлен файл собственных стилей css/custom.css;
- Реализована шапка с логотипом и кнопкой вызова модального окна;
- Навигационная панель (Bootstrap navbar) с возможностью сворачивания на мобильных устройствах;
- Hero-блок с приветственным текстом и стилизованной симуляцией терминала;
- Раздел категорий в виде 4-колоночной Grid-сетки Bootstrap;
- Сетка популярных команд с метками и краткими описаниями;
- Часто задаваемые вопросы (FAQ);
- Создан каркас модального окна обратной связи с возможностью его открытия и закрытия;
- Добавлен адаптивный подвал страницы (footer).

## Используемые технологии
- HTML5;
- CSS3 / Bootstrap 5;
- JavaScript (Bootstrap Bundle JS);
- Git / GitHub.
