# Контрольная работа №2
Тема: «CSS-фреймворки: разработка веб-интерфейсов»

## Название проекта
BashTutor — Образовательная платформа по командам Bash

## Описание
Образовательный веб-ресурс, предназначенный для изучения команд командной строки Bash. Проект содержит базовую навигацию, каталог категорий, популярные команды, схему обучения (Roadmap) и форму обратной связи. Сайт сверстан с использованием CSS-фреймворка Bootstrap.

## Структура проекта
```
bash-guide/
├── index.html       # Главная страница
├── catalog.html     # Страница каталога всех команд
├── roadmap.html     # Схема обучения (Mermaid)
├── css/
│   └── custom.css   # Пользовательские CSS стили
├── comands/         # Страницы команд
│   ├── comand-ls.html 
│   ├── comand-mkdir.html 
│   └── comand-cd.html   
└── README.md        # Описание проекта
```
## Реализованные Bootstrap-компоненты
- Navbar: Адаптивная навигация с гамбургер-меню на мобильных экранах.
- Modal: Модальное окно предложений новых команд с формой.
- Card: Карточки категорий и справочных команд с равной высотой (h-100).
- Forms: Поля form-control, выбор категории form-select, группы input-group и чекбоксы form-check.
- Badges: Метки сложности команд (bg-success, bg-primary, bg-warning).
- Alerts: Информационные плашки для пользователей.
- Buttons: Кнопки действий btn-primary, btn-outline-warning и btn-outline-primary.
