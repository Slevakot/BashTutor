mkdir

Файлы и папки

Описание

Команда mkdir (make directory) предназначена для создания новых директорий (папок) в файловой системе. Позволяет создавать как одиночные каталоги, так и сложные разветвленные деревья папок.

Синтаксис

Общий формат вызова команды:

mkdir [опции] [имя_каталога]

Примеры использования

1. Создание простой папки:

Создает каталог с указанным именем в текущей директории.

mkdir images

2. Создание вложенных каталогов (рекурсивно):

Флаг -p автоматически создает промежуточные родительские папки, если они еще не существуют.

mkdir -p project/src/components

3. Создание нескольких каталогов разом:

Позволяет создать несколько независимых папок за один запуск.

mkdir css js images

Популярные флаги

  • -p — создание промежуточных родительских директорий без вызова ошибок;
  • -v — вывод сообщения для каждого созданного каталога (режим отчета);
  • -m — установка прав доступа (chmod) сразу при создании папки.
