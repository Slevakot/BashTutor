cd

Файлы и папки

Описание

Команда cd (change directory) используется для перемещения между каталогами в файловой системе Linux. С ее помощью можно зайти в подпапку, подняться на уровень выше или вернуться в домашнюю директорию.

Синтаксис

Общий формат вызова команды:

cd [путь_к_каталогу]

Примеры использования

1. Переход в подпапку:

Перемещает в указанную директорию внутри текущего каталога.

cd documents/projects

2. Возврат на один уровень вверх:

Специальный символ .. указывает на родительский каталог.

cd ..

3. Переход в домашнюю директорию:

Быстрый переход в корневую домашнюю папку текущего пользователя из любого места.

cd ~

Особенности и ярлыки

  • cd - — мгновенный возврат в предыдущую директорию, в которой вы находились;
  • Простой вывод cd без аргументов также возвращает в домашний каталог;
  • Поддерживается автодополнение путей по клавише Tab.
