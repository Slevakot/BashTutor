ls

Файлы и папки

Описание

Команда ls (list directory contents) выводит список файлов и папок, содержащихся в текущей директории. Это одна из базовых и наиболее часто используемых команд в терминале Linux.

Синтаксис

Общий формат вызова команды:

ls [опции] [путь_к_каталогу]

Примеры использования

1. Просмотр файлов в текущей папке:

Выводит список файлов и директорий без скрытых элементов.

ls

2. Подробный список (формат long):

Выводит права доступа, количество ссылок, владельца, размер и дату изменения.

ls -l

3. Отображение скрытых файлов:

Показывает все файлы, включая те, чьи имена начинаются с точки (например, конфигурационные файлы вроде .gitignore).

ls -la

Популярные флаги

  • -l — подробный формат вывода;
  • -a — показать скрытые файлы;
  • -h — человекочитаемые размеры файлов (например, 4K, 25M);
  • -t — сортировка по времени изменения.
